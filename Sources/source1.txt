
الحلقة 01 — Chatbot vs Copilot vs Agent
مدة: 7–9 دقائق
الهدف: بعد الفيديو، المشاهد يفهم الفرق بين الثلاثة ويعرف علاش الـAgent مختلف جذريًا.
Style: شخص يفسّر + screen recording + diagrams بسيطة + demo.
🎯 الفكرة الأساسية للحلقة
ما نبدأوش بالتعريفات.
نبدأو بسؤال:
"شنوة الفرق بين AI يجاوبك، AI يعاونك، وAI ينجم يخدم المهمة وحدو؟"
ونستعملو نفس المشكلة في الحالات الثلاثة.
المثال: متجر إلكتروني
عندنا customer اسمو Ahmed وعندو order متأخرة.
نطلبو من الـAI:
"أحمد يقول إن طلبه ما وصلش. شوفلي المشكلة وحلّها."
ونشوفو كيفاش كل نوع AI يتصرف.

🤖 3. AGENT
هنا نعمل dramatic transition.
🎥 الشاشة
نفس السؤال:
"أحمد يقول إن طلبه ما وصلش. شوفلي المشكلة وحلّها."
لكن هذه المرة تظهر:
AI AGENT

Understanding request... ✓

Checking customer... ✓
Checking order... ✓
Checking delivery... ✓

Problem found:
Delivery delayed.

Suggested action:
Create support ticket.

[Approve]
نضغط Approve.
ثم:
Creating ticket... ✓

Ticket #847 created.

✓ Customer issue registered.
🎙️
"هنا دخلنا في عالم الـAgents.
المستخدم ما قالش:
'اعمل get_customer'
'بعدها اعمل search_order'
'بعدها create_ticket'.
هو عطى Goal.
والـAgent هو اللي قرر شنوّة الخطوات اللازمة لتحقيق الهدف."

⏱️ 06:10 — 07:00
⚠️ لكن Agent ≠ "خليه يعمل كل شيء"
هنا تعمل نقطة UX مهمة.
🎥 Visual
Agent يقول:
I found 17 delayed orders.

I can:
→ Create 17 support tickets
→ Notify customers

[Approve actions]
🎙️
"وهنا تبدأ الحاجة المهمة بالنسبة للـUX Designer.
Agent قوي موش معناها نعطيه access لكل شيء ونقولولو:
'تصرف وحدك.'"
ثم:
"كل ما الـAI عندو قدرة أكبر على الـAction، كل ما نحتاجو:
permissions،
confirmation،
visibility،
undo،
وhuman control."
