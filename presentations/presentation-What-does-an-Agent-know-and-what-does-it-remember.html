🔍 The Missing Piece

من أين يحصل الـ Agent على المعلومات؟

📚 Retrieval-Augmented Generation

ما هو الـ RAG؟

Search first, answer second. (ابحث أولاً، أجب ثانياً)

1. User Question
↓
2. Search Knowledge Base
↓
3. Find Relevant Information
↓
4. Give Information to AI
↓
5. Generate Answer
⚠️ Concept Check

RAG ≠ Training

Training

يغير ويبني المعرفة داخل الـ Model.

Model → Learns

RAG

لا يغير الـ Model. يزوده بالمعلومات وقت الحاجة (Runtime).

Model → Retrieves → Uses Info

Adding documents to RAG does not mean retraining the AI.

🧠 What Is Memory?

الذاكرة ليست أرشيفاً لكل شيء

Memory هي المعلومات التي نختار الاحتفاظ بها من تفاعلات سابقة.
الـ system يقرر: ماذا يحفظ، متى يسترجعه، ومتى يحذفه.

Ahmed │ ├── Preferred language: Arabic ├── Preferred contact: Email └── Order History access: Verified
⏱️ Context

السياق الحالي (Context)

Information available to the Agent right now.

Ahmed: "My order number is 1024."

(بعد ثواني)

Ahmed: "Where is it?"

الـAgent يملك "Order #1024" في الـ Context الحالي، دون الحاجة للبحث في الـ Memory.

⚖️ RAG vs Memory

المقارنة الشاملة

RAG (Find) Memory (Remember)
الهدف Find knowledge Retain information
المصدر External knowledge (DBs, Docs) Previous interactions / State
مثال Company policy User preference
السؤال الأساسي "Where can I find this?" "What do I remember?"

🎯 Key Takeaways

الخلاصة: 5 أفكار رئيسية

  • 1. AI Model ≠ Company Knowledge Base.
  • 2. RAG lets the Agent retrieve external knowledge.
  • 3. Memory lets the Agent retain useful info from the past.
  • 4. Context is what the Agent has available right now.
  • 5. Memory ≠ RAG ≠ Context.

§ 01
OPENING
في الحلقة اللي فاتت، شفنا كيفاش الـAgent يخدم بالـAgentic Loop. عندو Goal... يقرر شنوّة يعمل... يعمل Action... يشوف الـResult... وبعد يستعمل الـResult هذا باش يقرر شنوّة يعمل بعد. أما توا فما سؤال مهم: منين الـAgent يجيب المعلومات اللي يحتاجها باش يعمل الـDecision؟
§ 02
AI Knowledge
قبل ما نفسرو Memory وRAG، لازم نفهمو حاجة. كي نحكيو مع AI Model، الـModel عندو knowledge. يعني تدرب قبل على كمية كبيرة من المعلومات. أما توا نسألو: "شنوّة سياسة الإرجاع الخاصة بشركتي؟" هنا فما مشكلة. الـModel ما عندوش بالضرورة access للـdocuments متاع شركتك.
§ 03
RAG (Retrieval-Augmented Generation)
RAG معناها: قبل ما الـAI يجاوب، نخليوه يبحث على المعلومة اللي يحتاجها. يعني بدل ما نقولو للـAI: "جاوب من اللي تعرفو." نقولو: "استنى... خلينا نشوفو أولاً إذا عنا information مرتبطة بالسؤال." وهذا هو الفرق الكبير. إضافة document ما يعنيش Training، هو مجرد Retrieval.
§ 04
Memory
الـMemory هي information نختارو نحتفظو بيها من interactions سابقة أو من state متاع المستخدم. مثلاً: Ahmed يفضل التواصل بالعربي. النظام يحتفظ بالمعلومة هذي ويستعملها لاحقاً. الـMemory ليست كل شيء قاله المستخدم، هي Selective Information.
§ 05
Context
الـContext هو ما يحدث الآن (Right Now). Ahmed قال رقم الطلبية 1024. في نفس الحوار، الـ Agent يملك هذي المعلومة، لا حاجة للبحث ولا للذاكرة الطويلة، إنها موجودة في سياق المحادثة الجارية.
§ 06
The Big Picture
إذن عنا 3 مصادر: 1. RAG = Find knowledge. (معلومات خارجية مثل سياسة الشركة) 2. Memory = Remember information. (تفضيلات المستخدم السابقة) 3. Context = What's happening now. (الحوار الحالي)
§ 07
UX & Conclusion
دورنا كـ UX Designers أن نوضح للمستخدم من أين جاءت المعلومة. الذكاء الاصطناعي لا يجب أن يكون الصندوق الأسود (Black Box). اجعل النظام شفافاً للمستخدم. في الحلقة القادمة سنرى: ماذا لو لم يكن Agent واحد كافياً؟
