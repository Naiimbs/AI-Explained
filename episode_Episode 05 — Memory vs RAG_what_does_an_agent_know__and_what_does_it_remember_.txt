Episode 05 — Memory vs RAG
What Does an Agent Know, and What Does It Remember?
🎯 Episode Goal

في نهاية الحلقة، المشاهد يفهم الفرق بين:

Context → شنوّة الـAgent يعرف توا في الـconversation الحالية
Memory → شنوّة الـAgent يحتفظ بيه من الماضي
RAG → كيفاش الـAgent يلقى information من external knowledge
وعلاش Memory ≠ RAG
Core Message

RAG helps an Agent find knowledge.
Memory helps an Agent retain useful information.
Context gives the Agent what is happening right now.

03 — What Is RAG?
RAG = Retrieval-Augmented Generation
Simple definition

RAG = Search first, answer second.

بدل ما الـAI يخمن الإجابة، نخليه يبحث في knowledge source قبل ما يجاوب.

Flow
User Question
      ↓
Search Knowledge
      ↓
Find Relevant Information
      ↓
Give Information to AI
      ↓
Generate Answer
04 — RAG Real Example

عندنا company knowledge base:

Company Knowledge
│
├── Return Policy
├── Shipping Policy
├── Warranty
├── Product Documentation
└── FAQ

Ahmed يسأل:

"نجم نرجع المنتج بعد 10 أيام؟"

الـAgent يعمل retrieval.

يلقى:

Return Policy → Returns allowed within 14 days.

بعد يعطي الـinformation للـAI.

والـAI يجاوب Ahmed.

Important

الـAgent ما حفظش الـReturn Policy في memory متاع Ahmed.

هو فقط:

retrieved the information when needed.

05 — How RAG Works

نعطي concept تقني بسيط من غير deep technical details.

Step 1 — Documents

الشركة عندها documents.

Step 2 — Chunking

الـdocuments تتقسم إلى أجزاء صغيرة.

Step 3 — Embeddings

كل جزء يتحول إلى representation تساعد النظام يقارن المعنى.

Step 4 — Retrieval

لما user يسأل سؤال، النظام يبحث على أكثر أجزاء relevant.

Step 5 — Generation

الـrelevant information تتعطى للـAI.

والـAI يصيغ الإجابة.

       ↓
   Embeddings
       ↓
 Knowledge Base

       ↓
   Retrieval

    Answer
06 — RAG ≠ Training

هذه نقطة مهمة جداً.

Training

يغير / يبني knowledge داخل model.

RAG

ما يبدلش model.

هو فقط يعطي الـmodel information وقت الـruntime.

TRAINING
Model → Learns

RAG
Model → Retrieves → Uses Information
Key Message

Adding documents to RAG does not mean retraining the AI.

07 — What Is Memory?

توا ننتقلو للمفهوم الثاني.

Memory

Memory هي information نختارو نحتفظو بيها من interactions سابقة أو من state متاع المستخدم/المهمة.

مثلاً:

Ahmed يقول:

"أنا نفضل التواصل بالعربي."

النظام ينجم يحتفظ بالمعلومة.

بعد أسبوع يرجع Ahmed.

الـAgent ينجم يستعمل:

Preferred language: Arabic

هنا عنا:

Memory.

08 — Memory ≠ Remember Everything

مهم جداً نوضح:

Memory ما تعنيش:

"AI remembers every single thing."

الـsystem يقرر:

What to store
What not to store
When to retrieve it
When to update it
When to delete it
Example
Ahmed
│
├── Preferred language: Arabic
├── Preferred contact: Email
└── ...

الـmemory هي selected useful information، موش archive لكل conversation.

09 — Context

قبل ما نقارنو Memory وRAG، لازم نضيفو concept ثالث:

Context

Context هو:

Information available to the Agent right now.

مثلاً:

Ahmed:

"My order number is 1024."

بعد ثواني:

"Where is it?"

الـAgent عندو:

Order #1024

في الـcurrent conversation.

هذا:

Context.

موش بالضرورة Memory.

12 — RAG vs Memory
Comparison
	RAG	Memory
الهدف	Find knowledge	Retain information
المصدر	External knowledge	Previous interactions / state
مثال	Company policy	User preference
السؤال	"Where can I find this?"	"What do I remember?"
الاستعمال	عند الحاجة	حسب relevance
يتطلب training؟	❌	❌
Simplest explanation

RAG = Find

Memory = Remember

# 📚 WHAT IS RAG?

RAG اختصار لـ:

**Retrieval-Augmented Generation.**

الاسم يمكن يبان complicated...

أما الفكرة بسيطة جداً.

RAG معناها:

**قبل ما الـAI يجاوب، نخليوه يبحث على المعلومة اللي يحتاجها.**

يعني بدل ما نقولو للـAI:

**"جاوب من اللي تعرفو."**

نقولو:

**"استنى... خلينا نشوفو أولاً إذا عنا information مرتبطة بالسؤال."**

مثلاً عند الشركة documents:

**Shipping Policy**

**Return Policy**

**Warranty**

**FAQ**

**Product Documentation**

Ahmed يسأل:

**"نجم نرجع المنتج إذا فات عليه أسبوع؟"**

الـAgent ما يلزمش يخمن.

يعمل Search في الـcompany knowledge.

يلقى:

**Return Policy**

ويستخرج الجزء اللي يحكي على مدة الإرجاع.

بعد يعطي الـinformation هذي للـAI.

والـAI يستعملها باش يجاوب.

إذن العملية تقريباً:

**Question**

↓

**Search**

↓

**Find relevant information**

↓

**Give it to the AI**

↓

**Generate answer**

وهذا هو RAG.

# 🔍 علاش ما نعطيوش الـAI الـdocuments الكل؟

سؤال منطقي.

عندك مثلاً:

**10,000 documents.**

Ahmed يسأل سؤال صغير على:

**Return Policy.**

هل لازم كل مرة نبعثو الـ10,000 document للـAI؟

طبعاً لا.

هذا موش عملي.

لذلك الـRAG يعمل حاجة مهمة:

**يبحث على الجزء اللي عندو علاقة بالسؤال.**

مثلاً:

Ahmed:

**"شنوّة مدة الإرجاع؟"**

الـsystem يبحث.

يلقى:

**Return Policy — Section 3**

وهذا هو اللي يبعثو للـAI.

يعني:

**We don't give the AI everything.**

**We retrieve what it needs.**

وهذي نقطة مهمة.

# Memory.

Memory مختلفة على RAG.

RAG تساعد الـAgent يلقى information من **external knowledge**.

Memory تخليه يحتفظ بـinformation من **previous interactions أو state**، إذا النظام اختار يحفظها.

مثلاً Ahmed يقول:

**"أنا نفضل نتواصل بالعربي."**

الـAgent يتفاعل معاه.

وبعد conversation تسكر.

بعد يومين Ahmed يرجع.

ويقول:

**"عندي مشكلة في طلبية جديدة."**

إذا الـsystem عندو Memory مناسبة ومحفوظة للمعلومة:

الـAgent ينجم يعرف:

**Ahmed prefers Arabic.**

وبالتالي يواصل معاه بالعربي.

هنا ما عملناش search في company document.

إحنا رجعنا لمعلومة محفوظة من interaction سابقة.

وهذا هو:

**Memory.**

# 🔄 MEMORY DOESN'T MEAN REMEMBER EVERYTHING

وهنا لازم نصلحو misconception.

كي نقولو:

**"AI has memory."**

هذا ما يعنيش إنو الـAI يتذكر كل كلمة قلتها من أول conversation حتى لليوم.

موش هكا تخدم.

في systems حقيقية، الـapplication هي اللي تحدد:

**شنوّة information تتخزن؟**

**كيفاش تتخزن؟**

**وقتاش نستعملها؟**

**ووقتاش نمسحوها؟**

مثلاً ممكن نخزنو:

```text
Ahmed
Preferred language: Arabic
Preferred contact method: Email
```

هذي information ممكن تكون useful في interactions مستقبلية.

أما موش معناها نخزنو كل message قالها Ahmed.

# 💬 CONTEXT — CONCEPT ثالث مهم

وهنا فما concept ثالث لازم نفهموه:

**Context.**

Context هو المعلومات الموجودة **توا** قدام الـAI في الـcurrent interaction.

مثلاً:

Ahmed يقول:

**"وين وصلت الطلبية؟"**

وقبلها مباشرة قال:

**"رقم الطلبية هو 1024."**

المعلومة:

**Order = 1024**

موجودة في الـcurrent conversation.

هذا:

**Context.**

موش بالضرورة Memory.

لأنها information موجودة توا في conversation.

# 🧠 الفرق بين الثلاثة

إذن عنا:

### Context

**What is available right now.**

شنوّة موجود في الـconversation الحالية؟

---

### Memory

**What we intentionally remember from the past.**

شنوّة information اخترنا نخليوها محفوظة للمستقبل؟

---

### RAG

**What we retrieve from external knowledge.**

شنوّة information نحتاجو نبحثو عليها؟

يلقى مثلاً:

**Return Policy — Returns within 14 days.**

هذا الـpiece يرجع للـAgent.

والـAI يستعملو في الإجابة.

إذن:

**Question → Retrieve relevant knowledge → AI → Answer.**

---

# 🧠 MEMORY كيفاش تخدم؟

Memory تنجم تكون أبسط في الفكرة.

بعد interaction مع Ahmed، system ينجم يقرر:

**"هذي معلومة مفيدة للمستقبل."**

مثلاً:

**Ahmed prefers Arabic.**

تتخزن في memory.

في interaction مستقبلية:

Ahmed يرجع.

الـsystem يسترجع memory.

ويضيفها للـcontext الحالي.

وبالتالي الـAgent يعرفها وقت يعمل response.

يعني:

**Past information**

↓

**Memory**

↓

**Current Context**

↓

**Agent**

---

# ⚔️ MEMORY VS RAG — الفرق الحقيقي

توا إذا نحب نختصرها:

إذا نسألك:

**"وين نلقى المعلومات الخاصة بالشركة؟"**

الإجابة:

**RAG.**

إذا نسألك:

**"شنوّة نتذكر على Ahmed؟"**

الإجابة:

**Memory.**

إذا نسألك:

**"شنوّة قال Ahmed منذ ثواني في conversation الحالية؟"**

الإجابة:

**Context.**

# 🎨 UX PERSPECTIVE

وهنا الموضوع يولي مهم جداً من ناحية UX.

خاطر المستخدم يلزمو يعرف:

**شنوّة الـAgent يعرف؟**

**شنوّة يتذكر؟**

**ومن وين جاب المعلومة؟**

مثلاً الـAgent يقول:

**"حسب سياسة الشركة، تنجم ترجع المنتج خلال 14 يوم."**

من UX perspective، نجم نوري:

**Source: Return Policy**

المستخدم يقدر يضغط:

**View source**

ويشوف منين جات المعلومة.

هذا يزيد:

**Trust.**

---

# 👤 والـMemory؟

إذا الـAgent يقول:

**"بما إنك تفضل التواصل بالعربي..."**

المستخدم ممكن يسأل:

**"كيفاش عرفت؟"**

هنا UX لازم تعطيه transparency.

مثلاً:

**You told us you prefer Arabic.**

وممكن تعطيه:

**Manage Memory**

أو:

**Forget this information.**

المهم:

الـuser ما يحسش إنو الـAI عندو memory غامضة وما يعرفش شنوّة مخزن عليه.

---

# ⚠️ MEMORY CAN BECOME OUTDATED

وفما مشكلة أخرى.

Memory تنجم تولي قديمة.

مثلاً:

Ahmed كان يقول:

**"نحب نتواصل بالإيميل."**

وبعد شهر يقول:

**"من توا تواصلو معايا بالـSMS."**

إذا الـsystem ما حدثش الـmemory:

الـAgent ينجم يستعمل المعلومة القديمة.

لذلك Memory لازم تكون:

**manageable**

و:

**updatable**

وموش:

**store everything forever.**
